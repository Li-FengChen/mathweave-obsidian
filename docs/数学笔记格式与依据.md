# 数学笔记格式与依据

更新：2026-10-13 · 版本 2.1

公开资料没有统一、可信的“数学笔记格式最高评分”榜单。本项目根据 Obsidian 官方语法及数学笔记作者的实践，选择独立概念笔记、分类知识联系与原生 Callout，兼顾阅读、分享和长期维护。

## 默认结构

| 内容 | 原生语法 | 默认阅读状态 |
| --- | --- | --- |
| 定义、符号约定 | `[!abstract]` | 展开 |
| 定理、引理、推论 | `[!note]` | 展开 |
| 适用条件、反例提醒 | `[!warning]` | 展开 |
| 证明、证明思路 | `[!tip]-` | 折叠，点击标题展开 |
| 例题、例子 | `[!example]+` | 可折叠，默认展开 |
| 人工原文与合并来源 | `[!quote]-` | 折叠保留 |
| 依赖、推广、特例等 | Wikilink + 关系说明 | 双向记录 |

只有原资料实际提供的部分才写入笔记。不根据一个定理名称凭空补写证明。未知的证明可以注明待补充。

## 可复制模板

下面的 Markdown 可以直接保存为 Obsidian 笔记。每个 Callout 的空行和公式行也需要带 `>`。

```markdown
---
title: 平方函数的导数
kind: 定理
category: 微积分
tags: [数学, 导数]
review_status: 待核对
---

# 平方函数的导数

> [!abstract] 定义与记号
> $f(x)=x^2$，$x\in\mathbb{R}$。

> [!note] 定理
> $f'(x)=2x$。

> [!tip]- 证明
> 当 $h\ne0$ 时，
>
> $$
> \frac{f(x+h)-f(x)}h=2x+h.
> $$
>
> 令 $h\to0$，得到 $f'(x)=2x$。

> [!example]+ 例题
> 在 $x=1$ 处，导数为 $2$。

## 知识联系

- **依赖** [[导数]]：按差商极限定义求导。
```

程序预览采用本地 MathJax，并解析原生 Callout 的框与折叠状态。Obsidian 的主题、扩展宏和插件可能改变外观；完整 TeX 文档、TikZ 与外部宏文件不属于这个预览器的功能。

## 参考依据

[Obsidian 官方 Callout 文档](https://help.obsidian.md/callouts)说明原生框支持标题、嵌套和折叠，`-` 默认折叠，`+` 默认展开。因此证明折叠和定义框可以直接随 Markdown 分享。

数学笔记作者 [zhaoshen_zhai 的使用实践](https://www.reddit.com/r/ObsidianMD/comments/13lhyd7/one_year_of_math_notes_in_obsidian/)采用独立知识笔记，并区分推广、特例、构造、等价和证明依据等联系。本项目据此保留关系类型与理由，避免把所有共同出现的概念都连在一起。

[数学定理 Callout 插件作者的说明](https://ryotaushio.github.io/obsidian-latex-theorem-equation-referencer/theorem-callouts/theorem-callouts.html)展示了进一步的定理编号和引用功能。本项目默认使用原生类型；需要复杂编号时，可由用户在 Obsidian 中另外选择插件。
