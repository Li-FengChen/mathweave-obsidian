# 数学知识织网 · 使用教程

版本 2.2.1 · 更新于 2026-10-14

## 1. 两分钟开始

1. 将 Windows 分享压缩包**完整解压**到一个文件夹。
2. 双击 **数学知识织网.exe**，打开功能窗口。
3. 点击 **体验示例**，即可阅读示例笔记和正确排版的数学公式。
4. 点击右侧 **知识联系**，查看导数、泰勒公式与麦克劳林公式之间的关系。点击节点可以回到对应笔记。
5. 正式使用前，点击右上角 **设置**，选择自己的 Obsidian 仓库和 AI 服务。

体验示例无需 API 密钥。它使用内置教学内容，帮助你熟悉功能；你的真实对话需要点击“提取知识与联系”重新分析。

## 2. 首次配置

### 选择笔记保存位置

在设置中，选择你现有的 **Obsidian 仓库文件夹**。通常这个文件夹包含 .obsidian 子目录。

“笔记子目录”默认是 **数学笔记**。程序会在仓库中创建该目录，不影响其他目录。子目录必须位于所选仓库内。

### 配置 AI

- **AI 服务商**：选择你使用的服务，或选择 custom 填写兼容接口。
- **服务地址**：按服务商提供的 API 地址填写。
- **模型名称**：填写你账号或本地服务实际可用的模型名称。
- **API 密钥**：自动载入当前服务商已保存的密钥，默认隐藏。第一次使用时输入自己的密钥，点击保存后存入这台电脑的系统密钥链。
- **最大输出长度**：知识点多或正文长时适当提高；仍须符合所选模型的限制。
- **生成温度**：默认 0.2，适合较稳定的知识整理。

密钥右侧的 **显示／隐藏** 按钮可以切换是否显示完整内容。点击 **删除** 清空输入后，再点击设置底部的 **保存**，才会删除已存密钥；点击 **取消** 则保留原密钥。仅手动清空输入仍会保留原密钥。

切换 AI 服务商会载入该服务商自己的密钥，并恢复隐藏。本次对其他服务商密钥的修改或删除会保留，点击保存时一并生效。不要把密钥发给其他人。

如果通过环境变量提供密钥，页面会说明来源。程序内清空输入不会删除系统环境变量；如需彻底移除，请在系统设置中删除相应的环境变量。

已经保存的密钥可以直接点击 **测试已配置的连接**。若本次修改或删除了密钥，先保存设置，再重新打开设置测试。密钥、模型或地址有误时会显示原因。

采用本地 Ollama 时，先在自己的电脑启动该服务，再在设置中选择 ollama，并填写已安装的模型。无需云端密钥。

开启 AI 时，对话会发送到你选择的服务。仅文件解析、公式预览和体验示例在本地执行。

### 本地模式

取消“使用 AI 提取知识点和数学关系”，即可尝试本地启发式提取。此模式不访问 AI 服务，主要根据文本与数学标记识别内容，知识点分类和数学关系的完整程度有限。

本地模式只根据正文明确提及的知识点建立“提及”联系，不把它当作已经确认的数学依赖关系。

## 3. 日常操作

### 第一步：放入对话

在左栏粘贴完整对话，或点击“导入文件”选择 txt、md、json。

支持普通文本、带 User:/Assistant: 或中文角色标记的文本、OpenAI messages 数组，以及含 mapping 的会话导出。导出中存在 current_node 时，按对应分支恢复对话；若存在多个答案分支而未指定当前节点，会明确拒绝混合导入；会话列表会依次导入其中的对话。

尽量包括问题、解释、推导和后续纠错，避免只复制零散公式。导入错误不会静默丢弃无法解码的字符；必要时将原文件另存为 UTF-8。

### 第二步：提取知识与联系

点击紫色按钮。程序在后台分析，处理进度出现在左栏底部。

网络请求较慢时可以取消。取消会在当前请求结束后停止，不保存本次结果；关闭窗口时也会等待当前任务退出。

### 第三步：阅读与校对

中栏显示提取到的知识点。点击一项，在右栏查看：

- **笔记预览**：阅读排版后的正文、数学公式与知识联系。
- **编辑笔记**：修改标题、分类、标签和正文。标签用逗号分隔。
- **知识联系**：查看关系图和每条关系的说明。点击节点或内部链接切换笔记。

可以在“编辑笔记”中点击“修改知识联系”，增删关系、选择目标并修改说明；反向联系会一起更新。

点击“应用修改并预览”，或从编辑页切换到预览页，修改会应用到待保存结果。修改关联知识点的标题时，本次结果中的目标名称会一起更新。

勾选中栏中要保存的知识点。取消勾选只是不创建该篇笔记；其他笔记中对它的关联可以保留，便于以后补充。

### 第四步：保存到 Obsidian

在保存按钮上方，选择是否勾选 **更新已有笔记**：

- **未勾选（默认）**：本次笔记独立保存到数学笔记/独立导入中的新文件夹，生成本次知识地图与分类索引，原有笔记和索引保持原样。本次知识点之间的联系仍会保留。
- **勾选**：同名笔记补充到原文件中，保留人工内容，并按照设置核对新旧笔记的联系、更新原分类索引。

每次重新提取或载入示例后，选项恢复为不勾选。重复保存同一次导入会跳过；更改本次笔记内容后，独立保存会另建一个版本，保留前一次保存。

点击绿色按钮。程序会：

1. 为选中的知识点生成 Markdown 笔记。
2. 写入知识关系、双向链接和简短说明。
3. 生成一篇 **对话知识地图**，保留本次对话的整体主题和联系。
4. 按设置更新 **数学知识索引**。

可以先点击“变更预览”查看新旧差异；该步骤不写入笔记，之后选择保存这些变更。直接点击“保存到 Obsidian”则自动完成。

本次勾选“更新已有笔记”，并开启设置中的“保存时用 AI 核对与已有数学笔记的联系”时，会先比较新笔记与数学子目录中的已有笔记，补充有依据的双向链接。教学示例及本地模式不会调用这项 AI 核对。

保存完成后，窗口中央会显示“保存成功”和“新增、更新、跳过”数量，约 3 秒后自动消失，无需点击确认。底部状态和处理记录仍可查看保存详情。相同结果再次保存会跳过；勾选更新后，不同内容保存到同名笔记时保留旧正文，完整追加补充记录，避免覆盖人工内容。

更新前的事务备份位于仓库根目录 .agent_backup/transactions。每个操作有独立目录和 manifest.json；原文件以编号 .bin 保存，manifest 记录对应笔记路径。整理前原正文还会保留在主笔记中的折叠来源记录。

## 4. 一键整理已有笔记库

配置仓库和 AI 后，点击窗口右上角 **AI 整理笔记库**。窗口打开后会按照设置中的默认范围开始自动整理，无需再确认。

默认范围是 **数学笔记子目录**。你可以在设置中修改默认值，或在整理窗口完成当前任务后切换为“整个仓库中的数学笔记”再次整理。隐藏目录、索引、对话地图和已合并的跳转笔记会跳过。

程序会依次完成：

1. 读取数学笔记，寻找疑似重复概念与有依据的联系。
2. 用待合并笔记的完整正文进行二次核对，保留条件、证明与人工备注。
3. 合并为主笔记，原正文放在折叠来源记录里；旧文件改为指向主笔记的跳转。
4. 添加双向知识联系，统一定义、定理、证明和例题格式，并更新分类索引。
5. 创建事务快照后写入，显示合并依据与结果。

“整理记录”显示过程与跳过原因；“全部变更”显示新旧差异；“整理后的笔记”可查看公式和折叠框。

整理窗口首次打开时会自动执行。后续手动开始前，可以勾选 **仅生成方案，先查看变更**；此时不写入笔记，确认后才点击“应用此方案”。若要在首次整理前就预览而不写入，可通过命令行运行 `main.py --cli --maintain --preview --vault "D:\MyVault"`。

点击 **撤销最近一次整理**，恢复上次操作前的笔记、索引和元数据。若整理后又编辑了相关文件，自动撤销会停止并保留后续内容；可以点击“打开备份文件夹”核对原始快照。“取消当前任务”会停止后续 AI 请求；写入期间取消会尝试恢复本次修改。

默认合并最低置信度为 0.94，并要求两次核对均通过。不确定或正文超出输入预算的合并会跳过并写入提示。大型笔记库采用分段与候选检索，可能仍有本轮未发现的隐含联系。

AI 整理需要使用配置中的 AI 服务。目录摘要和需要合并的正文会发往该服务；新旧笔记联系核对也会发送相应摘要。

### 新设置说明

保存时核对已有笔记联系的设置，只在本次导入勾选“更新已有笔记”时生效。“AI 整理笔记库”仍是单独的操作；它按你选择的范围维护已有笔记，不受本次导入勾选项限制。

- **分类索引名称**：可自定义索引笔记名。
- **数学相关度阈值**：在 0–1 之间；提高时更严格，调低时保留更多候选内容。
- **每段输入长度**：默认 16000 字符。长对话在完整段落边界分段；超过上限的单个公式/代码块会明确提示，不截掉原文。这个字符预算不等于模型的 token 数，必要时按服务能力调低。
- **AI 输出模式**：默认自动兼容；只有服务明确拒绝 JSON 参数时才改为提示词约束，结果仍严格校验。可选择强制或关闭该参数。
- **数学笔记框与可折叠证明**：控制新建与整理的数学排版。
- **整理笔记上限、最低置信度**：控制单次整理规模与自动合并的保守程度。

## 5. 知识关系如何保留

例如，一次对话同时讲到三个知识点：

- **泰勒公式依赖导数**：系数由同一点的各阶导数决定。
- **麦克劳林公式是泰勒公式的特例**：展开点取零。
- **矩阵与行列式**：如果对话没有提供它与泰勒公式的联系，就保持独立。

程序保留这些独立笔记，并用 Obsidian 的双向链接表示关系。导数笔记里可以看到“被依赖：泰勒公式”，泰勒笔记里可以看到“依赖：导数”。

同一对话中出现多个概念，并不代表它们都应互相连接。程序要求根据对话实际讨论的联系建立关系，避免生成没有依据的知识网络。

AI 可能遗漏或误判关系。预览后检查定理条件和关系说明，再保存；已保存笔记也可以继续在 Obsidian 中编辑。

## 6. 数学公式的写法

预览采用与 Obsidian 数学语法相容的 MathJax，所有渲染资源随程序打包，断网也能预览。定义、定理、例题用原生 Callout 显示，证明标题可以点击折叠或展开；完整模板与选择依据见随包“数学笔记格式与依据.md”。

### 行内公式

在正文中使用单美元符，例如：

    导数为 $f'(x)$，展开点为 $a$。

也支持括号分隔符：

    \(\alpha+\beta\)

### 独立公式

用双美元符包裹：

    $$
    f(x)=\sum_{k=0}^{n}\frac{f^{(k)}(a)}{k!}(x-a)^k+R_n(x)
    $$

预览效果：

$$
f(x)=\sum_{k=0}^{n}\frac{f^{(k)}(a)}{k!}(x-a)^k+R_n(x)
$$

### 矩阵

    $$
    \begin{pmatrix}a&b\\c&d\end{pmatrix}
    $$

### 多行对齐

    $$
    \begin{aligned}
    e^x &\approx 1+x+\frac{x^2}{2},\\
    \sin x &\approx x-\frac{x^3}{6}.
    \end{aligned}
    $$

### 分段函数

    $$
    f(x)=\begin{cases}x^2,&x\ge0,\\-x,&x<0.\end{cases}
    $$

### 不能正确预览时

先检查美元符是否配对、花括号是否闭合，以及矩阵换行是否用了两个反斜杠。代码块中的公式按代码显示，不会排版成数学公式。

不要把整篇笔记包在代码块中。对话里的双重转义可能需要在“编辑笔记”页改回正常 LaTeX，例如数学命令 \frac 在 Markdown 正文里只需要一个反斜杠。

预览支持常见数学扩展与 \newcommand；不运行完整 TeX 文档、外部宏文件或自定义 Obsidian 插件。相同数学语法的排版相近，Obsidian 的主题、插件与自定义宏设置仍可能使外观不同。

语法参考：[Obsidian 数学说明](https://help.obsidian.md/advanced-syntax)、[MathJax TeX 支持](https://docs.mathjax.org/en/v3.2/input/tex/index.html)。

## 7. 文件在哪里

    你的 Obsidian 仓库/
    ├─ 数学笔记/
    │  ├─ 导数.md
    │  ├─ 泰勒公式.md
    │  ├─ 麦克劳林公式.md
    │  ├─ 对话知识地图-xxxxxxxx.md
    │  ├─ 数学知识索引.md
    │  └─ .agent_meta.json
    └─ .agent_backup/

.agent_meta.json 保存文件对应关系与去重信息，建议与笔记一起备份，不要随意删除。

程序配置和日志保存在当前用户目录下的 .math_obsidian_agent；密钥保存在系统密钥链，不写入笔记，也不写进分享包。

## 8. 常见问题

**第一次想试用，但没有 API 密钥。**  
点击“体验示例”，无需配置即可查看效果；真正自动整理自己的复杂对话需要配置 AI，或尝试能力较有限的本地模式。

**别人收到了程序却打不开。**  
让对方完整解压整个文件夹，再双击 exe；不要在压缩包中直接运行，也不要只复制 exe。当前提供的是 Windows x64 包，其他系统需要单独构建。

**点击保存时让我选择仓库。**  
这是因为还没有配置保存位置。设置自己的 Obsidian 仓库即可。

**相同概念出现补充记录。**  
勾选“更新已有笔记”后，程序保留旧内容，并追加完整的新整理内容。可以点击“AI 整理笔记库”进一步归纳，旧原文和人工备注会继续保留。

**关系图里的链接没有对应笔记。**  
该知识点可能未勾选保存，或对话只提到了外部相关概念。可以以后补充这篇笔记；程序不会凭空编写其内容。

**是否必须安装 Obsidian？**  
程序可以直接保存 Markdown 文件，但在 Obsidian 中可以使用链接、反向链接和图谱查看知识网络。

## 9. 如何分享

把 [GitHub Releases](https://github.com/Li-FengChen/mathweave-obsidian/releases) 中的 `MathWeave-<版本>-Windows-x64.zip` 发给对方。对方完整解压后运行，配置自己的仓库与 API 密钥。

同时提供源码压缩包，方便学习、修改或重建；不要分享你的个人配置目录、密钥或实际仓库。详细更新和打包步骤见随包提供的“分享与打包.md”。
