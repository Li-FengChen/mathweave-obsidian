# 分享与打包

## 分享给朋友：只需要发送两个压缩包

- **数学知识织网-2.2.1-Windows.zip**：完整运行包，对方无需安装 Python。
- **数学知识织网-2.2.1-源码.zip**：程序源码、图标、本地渲染资源、依赖版本和构建脚本。

告诉对方：先完整解压 Windows 包，再双击“数学知识织网.exe”；先点“体验示例”，正式使用时再配置自己的 Obsidian 仓库、服务地址、模型和密钥。

不要只发送 exe。它需要同目录下的 _internal 文件夹，里面是 Python、Qt、浏览器内核和本地公式资源。当前程序包适用于 Windows 10/11 x64；本次在 Windows 11 上验证。

分享文件是本地生成的，程序不会自动上传到任何平台。你可以通过自己选择的聊天软件、网盘或 U 盘发送。

## 哪些私人数据没有打包

分享包按公开文件清单生成，排除了开发环境、测试仓库、个人日志、系统密钥链和用户配置。

接收者的设置独立保存在自己的用户目录里，密钥也保存到自己的系统密钥链。分享你的程序，不代表分享你的 API 配额。

## 给朋友发送更新

发送新版本的完整 Windows 包，让对方解压到新目录并运行即可。用户配置位于个人用户目录，通常可以继续使用；笔记位于对方选择的 Obsidian 仓库，不在程序目录中。

更新不需要替换或者删除对方的仓库。保留旧版本目录也不会占用同名笔记的保存位置。

## 如何重新构建

在 Windows x64 上安装 Python 3.12（本次验证版本）。源码根目录提供 build_windows.ps1：

    powershell -File .\build_windows.ps1

该脚本只在项目 .venv 中安装依赖，准备本地渲染资源，再生成可运行文件夹和两个分享压缩包。网络只用于下载构建依赖与公开渲染资源；程序日常预览不依赖这些下载地址。

开发者也可分步执行：

    .venv\Scripts\python.exe -m PyInstaller --noconfirm MathWeave.spec
    .venv\Scripts\python.exe tools\package_release.py

构建脚本会先跑回归检查，并验证生成的独立程序，再生成分享包。

requirements-lock.txt 记录本次实际验证的依赖版本。若要复现这个 Windows / Python 3.12 环境，可用该文件安装；其他系统或 Python 版本的可用包可能不同。

release/SHA256-2.2.1.json 记录两个压缩包的校验值，方便验证文件传输完整性。
